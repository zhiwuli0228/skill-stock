# Workspace and Template Boundary

## Principle

Skill is capability. Workspace is task data.

## Skill directory may contain

- default template
- empty QCC template
- scripts
- page-type rules
- examples
- acceptance checklist

## Skill directory must not contain

- real project data
- real project reports
- user evidence files
- generated final PPT outputs

## Template priority

1. User custom template in workspace
2. Skill default template

## Data rule

Business content must be provided by the user. If no data is available, this visual enhancer should not invent content. It should only enhance the supplied baseline or ask for a baseline PPT.
