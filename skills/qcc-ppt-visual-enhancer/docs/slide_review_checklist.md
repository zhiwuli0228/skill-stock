# Slide Review Checklist

Use this checklist after rendering the PPT.

## Page-level checks

- [ ] Title is readable and aligned with template.
- [ ] Subtitle does not compete with title.
- [ ] Main body has no large unexplained blank area.
- [ ] Page has one clear visual focus.
- [ ] Cards are not floating in a small region.
- [ ] Tables do not look like raw Excel dumps.
- [ ] Footer is consistent.

## Text checks

- [ ] Main body text is readable.
- [ ] No text overflows its shape.
- [ ] Important numbers are visually prominent.
- [ ] Captions are not too small.

## Badge checks

- [ ] Numbers/letters inside circles are optically centered.
- [ ] Badge size is consistent within the same page.
- [ ] Badge text color has enough contrast.

## Delivery checks

- [ ] PPTX generated.
- [ ] PDF generated.
- [ ] PNG render generated.
- [ ] Visual review report generated.
