# Badge Alignment Rules

## Problem

PowerPoint circle text can appear visually above the center even when horizontal and vertical alignment are set to center.

## Rule

For score circles, sequence badges, and role badges:

- use a circle shape only for the visual background
- place a separate text box on top when precise centering is required
- align the text box to the circle center
- use optical vertical correction when rendered text appears high

## Acceptance

The number/letter must look centered in the rendered PNG, not only in the PPTX object model.

## Typical badge types

- score badges: 1/2/3/4/5
- sequence badges: 1/2/3/4
- role badges: Q/R/E
- summary badges: 24, 100%, PASS
