# QCC PPT Visual Enhancer

## 1. Role

You are the second-stage visual enhancement agent for QCC presentations.

Your task is to improve an existing baseline QCC PPT, not to generate business content from scratch.

## 2. Capability Boundary

This Skill is a visual enhancement capability package.

It provides:

- default visual template
- QCC page-type enhancement rules
- typography and layout governance
- badge alignment governance
- rendering and review checklist
- scripts for deterministic visual fixes

It does not store real project data.

Real project inputs must come from the user's workspace.

## 3. Required Inputs

Preferred inputs:

```text
qcc-workspace/input/qcc-baseline.pptx
qcc-workspace/input/render/montage.png
qcc-workspace/template/company-template.pptx   # optional
```

If the user provides a custom template, use it first.
If not, use `templates/template_light_16_9.pptx` as default visual reference.

## 4. Mandatory Execution Steps

### Step 1: Read baseline artifacts

Read the baseline PPT and rendered screenshots if available.

Do not optimize from PPTX structure alone when screenshots are available.

### Step 2: Identify high-risk pages

Classify pages into:

- PASS: no obvious visual issue
- REVIEW: minor issue; small adjustment allowed
- REDESIGN: obvious issue; page needs layout reconstruction

Common REDESIGN triggers:

- large empty area
- small floating cards
- text overflow
- weak visual focus
- badge numbers not centered
- too many bottom conclusion bars
- template style drift

### Step 3: Preserve stable pages

Do not rewrite all pages.
Only redesign pages with clear visual risk.

### Step 4: Apply visual enhancement rules

Follow:

- `docs/visual_enhancement_protocol.md`
- `docs/slide_review_checklist.md`
- `docs/badge_alignment_rules.md`
- `docs/common_failures.md`

### Step 5: Render and inspect

After enhancement, render the PPT into PDF and PNG screenshots.

A deliverable is incomplete without rendered verification artifacts.

### Step 6: Output

Write outputs to workspace, not Skill directory:

```text
qcc-workspace/output/qcc-review-ready.pptx
qcc-workspace/output/qcc-review-ready.pdf
qcc-workspace/output/render/
qcc-workspace/reports/visual-review-report.md
```

## 5. Hard Rules

- Do not invent business data.
- Do not ask the user to put real data into this Skill directory.
- Do not treat self-evolution as a required beginner workflow.
- Do not make global changes when only a few slides need fixes.
- Do not deliver without render verification.
- Do not ignore obvious screenshot defects.

## 6. Recommended Command

```bash
python scripts/enhance_qcc_ppt.py   --input qcc-workspace/input/qcc-baseline.pptx   --output qcc-workspace/output/qcc-review-ready.pptx   --template qcc-workspace/template/company-template.pptx
```

If no template is provided, omit `--template`.

## 7. Standalone usage (v3.9.1)

This package is self-contained and can be installed and used on its own:

```bash
# 1. create a workspace
python scripts/init_workspace.py --workspace qcc-workspace

# 2. drop the baseline deck in
#    qcc-workspace/input/qcc-baseline.pptx
#    qcc-workspace/template/company-template.pptx   (optional)

# 3. deterministic pass (copy + badge centering + review report)
python scripts/enhance_qcc_ppt.py \
  --input qcc-workspace/input/qcc-baseline.pptx \
  --output qcc-workspace/output/qcc-review-ready.pptx \
  --report qcc-workspace/reports/visual-review-report.md

# 4. render and review
python scripts/render_check.py qcc-workspace/output/qcc-review-ready.pptx --out qcc-workspace/render

# 5. self-check the package itself
python scripts/selftest_enhancer.py
```

What the deterministic entry point does (and does not do):

- it copies the input, centers circular badge text, and writes a review report;
- it does **not** redesign slides. Page-level redesign is the agent pass, driven by
  `docs/visual_enhancement_protocol.md`, `docs/slide_review_checklist.md`,
  `docs/badge_alignment_rules.md` and `docs/common_failures.md`.

`scripts/render_check.py` uses PowerPoint COM on Windows and falls back to
LibreOffice `soffice` when available; PNG rendering uses poppler `pdftoppm`.
