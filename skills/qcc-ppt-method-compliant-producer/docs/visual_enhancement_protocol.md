# Visual Enhancement Protocol

## Goal

Upgrade a baseline QCC PPT from usable to business-review-ready.

## Enhancement scope

Focus on:

- visual hierarchy
- slide density
- card layout
- typography
- badge alignment
- template consistency
- footer consistency
- page-level visual focus

## Page risk classification

### PASS

No clear visual defect. Preserve the page.

### REVIEW

Minor issue. Apply targeted fixes only.

### REDESIGN

Major issue. Rebuild the page using a known layout pattern.

## High-risk signals

- main content uses less than 55% of body area
- cards are too small and float in the upper area
- text size is below readable threshold
- a page lacks one clear visual focus
- content is text-heavy but not structured
- badge numbers/letters are visually off-center
- page looks unlike the selected template

## Output rule

Each enhanced page should have:

- one clear page conclusion
- one visual focus
- stable alignment grid
- no obvious overflow
- no decorative clutter
