# QCC Page Contract (v5.0)

## 1. 目的

本契约把标准十步法（`docs/qcc_methodology.md`）落到页面上：每一页不仅有方法名称，
还必须承载该步的输入、数据证据与结论。页面标题是审查入口，但不是合规本身。

## 3. 标题规则

方法页统一使用 `阶段｜方法` 形式，例如：

```text
主题选定｜主题评价
现状把握｜柏拉图：识别关键 80% 改进项
解析｜真因验证
对策拟定｜5W1H
效果确认｜有形成果
```

禁止用通用标题替代方法页：`问题分析`、`现状说明`、`原因分析`、`改进措施`、`成果展示`。

## 4. 页面合并规则

默认不合并必需页面。确需压缩页数时，必须同时满足：

1. 标题显式写出所有被合并的方法名；
2. 每个方法保留可识别的形态与必备字段；
3. 渲染后文字与图表不重叠、不溢出。

## 5. 缺数据规则

缺数据时保留页面结构，显式标注缺什么：

```text
现状把握｜柏拉图：识别关键 80% 改进项
待补充：问题类别、各类频次、收集期间与样本量。
当前页保留柏拉图结构，补齐数据后生成正式图表。
```

缺数据页在合规检查中判为 `INCOMPLETE`，整体 `NON-COMPLIANT`。

## 6. 与旧版（v4.x）的主要差异

- 新增：主题评价、活动计划、目标设定、效果确认（有形成果+无形成果）、检讨与改进。
- 移出：SIPOC 不再作为现状把握的必需方法（只可作背景参考）。
- 归位：查检表从“主题评审”移到“现状把握”。
- 深化：鱼骨图之后必须经过要因评价与真因验证；5W 升级为 5W1H + 对策评价 + 真因映射。

## 7. 模板使用规则（v5.0 补充）

当使用 skill 自带模板（`qcc-empty-template.pptx` / `template_light_16_9.pptx`）或用户模板时：

1. **保留模板的封面、目录、结束页与母版背景**；背景、母版图片和主题色不得替换。
2. 正文页沿用模板的**配色、字体、标题样式与卡片语汇**（标题 + 短下划线 + 说明行 + 指标卡 + 结论条）。
3. **不得把模板里的占位小框当作正文容器**：模板占位框的尺寸对应标签、数值或短句；
   向其中填入长句会造成文字挤压、自动缩小与版式错乱。
4. 填充模板页时按**语义映射**：标题框只放标题，数值框只放数值，说明框只放短句；
   当内容与既有框位不匹配时，改用模板版式重建该页，而不是硬塞。
5. 交付前必须做渲染复核（截图/PDF）与格式审计；出现挤压、重叠、字号异常即判为不通过。
