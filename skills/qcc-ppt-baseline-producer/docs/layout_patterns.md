# Layout Patterns

The generator must classify each slide into a page type and use the corresponding layout. Do not place content arbitrarily.

## Page types

| Page type | Use case | Main layout |
|---|---|---|
| cover | Title page | Template cover, no extra title background. |
| agenda | TOC | Four-stage agenda. |
| circle-profile | Circle introduction | Identity + roles + evidence responsibility + activity mechanism. |
| topic-selection | Topic decision | Scoring table + topic rationale. |
| current-state | Baseline problem | Four-row situation table + three pain points. |
| target-setting | Targets | KPI cards + target rationale. |
| cause-analysis | Cause analysis | Six-dimension cards + convergence. |
| key-factor-confirmation | Key factors | Evidence matrix. |
| countermeasure-mapping | Countermeasures | Factor -> countermeasure -> validation table. |
| process-chain | Closed-loop mechanism | Large horizontal chain with arrows. |
| safety-gate | Multiple control points | Compact 2x4 cards plus flow arrows and one summary strip. |
| evidence-chain | Evidence chain | Before -> Command -> After -> Audit. |
| logic-chain | Constraint -> countermeasure -> result | Tall three-column cards using the main content area. |
| validation-system | Tests | KPI strip + layered validation table. |
| effect-before-after | Effects | Before/after rows + optional KPI summary. |
| risk-closure | Risks | KPI strip + six risk cards; no bottom noise. |
| standardization | Assets | Five-row standardization asset map. |
| roadmap | Next steps | Short/mid/long roadmap using tall cards. |
| summary | Final conclusion | PDCA summary + core conclusion. |

## Space utilization rules

- Main content should occupy 55%-75% of vertical content area on dense slides.
- Avoid small cards floating in the upper half with large lower blank space.
- Multi-card pages should use card height >= 1.05in unless the card is a KPI chip.
- Logic-chain pages should use tall cards >= 2.2in.
- Risk-closure pages should use two full rows of cards and avoid redundant bottom bars.

## Text rules

- Body text should be at least 9pt.
- Prefer 2-4 short lines per card.
- Avoid paragraphs in cards.
- Key numbers must be visually emphasized and stay inside their own cards.
- Do not put detail text outside the card it belongs to.

## Repair rules

If a slide has too much blank space:

1. enlarge the cards;
2. increase row height;
3. add one meaningful summary strip;
4. move secondary KPI cards into the main flow;
5. split the slide if content is too sparse and unrelated.

If text overflows:

1. shorten text;
2. increase card height;
3. reduce number of cards;
4. split into two slides;
5. only then slightly reduce font size, never below minimum.
