# QCC PPT 工作区模板

本目录只用于存放某一次 QCC PPT 生产任务的输入、模板、输出和验收报告。  
不要把真实项目数据长期放进 Skill 目录。

```text
qcc-workspace/
├── input/
│   ├── qcc-data.yaml
│   ├── evidence-index.yaml
│   └── source-materials/
├── template/
│   └── company-template.pptx        # 可选；不提供则使用 Skill 默认模板
├── output/
└── reports/
```

无 `qcc-data.yaml` 时，Skill 只能生成完整 QCC 空白模板，不得编造业务内容。
